One line, 138 characters, that gives the judge a quiet, earned moment of
pride: a man who signed with an X for forty years finally writing his
name in full — on his granddaughter's birthday card, in ink, without
asking for help. `main.py` (Python 3.13 standard library only) writes
the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
